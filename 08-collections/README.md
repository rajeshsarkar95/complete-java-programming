# 08 — Collections Framework

- `List`: ordered collection, permits duplicates (`ArrayList`, `LinkedList`)
- `Set`: unique elements (`HashSet`, `TreeSet`)
- `Map`: key-value pairs (`HashMap`, `TreeMap`)
- `Queue`: elements processed in queue order (`ArrayDeque`, `PriorityQueue`)
- `Collections` and `Arrays`: utility algorithms
Choose a collection based on ordering, uniqueness, lookup, and performance requirements.
