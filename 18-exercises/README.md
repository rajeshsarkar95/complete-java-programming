# 18 — Practice Exercises

Solve each problem without looking up a solution first. Add tests for edge cases.

## Beginner
1. Print your name and age.
2. Check whether a number is even or odd.
3. Find the largest of three numbers.
4. Print a multiplication table.
5. Calculate factorial.
6. Check whether a number is prime.
7. Reverse an integer.
8. Check whether a string is a palindrome.
9. Find the sum and average of an array.
10. Count vowels in a string.

## Intermediate
11. Find the second-largest array element.
12. Remove duplicates from an array.
13. Count the frequency of each character.
14. Check whether two strings are anagrams.
15. Find the first non-repeating character.
16. Implement binary search.
17. Merge two sorted arrays.
18. Find the maximum subarray sum.
19. Validate balanced parentheses using a stack.
20. Find the first repeated element.

## Advanced
21. Implement a generic linked list.
22. Implement an LRU cache.
23. Find shortest paths in a graph.
24. Solve coin change using dynamic programming.
25. Build a thread-safe counter.
26. Build a producer-consumer example.
27. Create a file-backed expense tracker.
28. Design a library management system using OOP.
