# 17 — Mini Projects

Build these projects in increasing difficulty:
1. Calculator — arithmetic operations and input validation.
2. Student Grade Manager — store students and calculate grades.
3. Bank Account Simulator — deposit, withdraw, transaction history.
4. Library Management — books, members, issue/return.
5. Expense Tracker — categories, totals, file persistence.
6. Quiz Application — questions, scoring, replay.
7. Contact Book — search, add, update, delete contacts.

Suggested improvements: split code into packages, add tests, validate input, persist data, and document design decisions.
