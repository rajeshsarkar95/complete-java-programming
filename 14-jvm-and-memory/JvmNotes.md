# JVM quick notes

- **JDK:** tools for developing Java applications, including the compiler.
- **JRE:** runtime components needed to run Java applications (modern JDK distributions package the runtime).
- **JVM:** executes Java bytecode.
- **Heap:** memory area where objects are generally allocated.
- **Stack:** per-thread call frames and local variables.
- **Garbage collection:** reclaims heap memory for objects that are no longer reachable.
- **JIT:** compiles frequently executed bytecode into native machine code.
