# 14 — JVM and Memory

Study:
- JVM, class loading, bytecode execution
- Heap, stack, metaspace, program counter and native method stacks
- Garbage collection and object reachability
- JIT compilation
- `equals()` and `hashCode()`
- Memory leaks caused by unintended object references
- Profiling, thread dumps, heap dumps

The JVM manages memory, but developers must still release external resources and avoid retaining objects unnecessarily.
