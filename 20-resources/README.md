## Glossary
- **Class:** blueprint for objects.
- **Object:** instance of a class.
- **Method:** named block of behavior.
- **Constructor:** initializes a new object.
- **Interface:** contract that classes can implement.
- **Exception:** event that disrupts normal execution.
- **Generic:** type parameter used for reusable type-safe code.
- **Collection:** object that groups multiple elements.
- **Thread:** independent path of execution.
- **Bytecode:** platform-independent instruction format executed by the JVM.
